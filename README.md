# Phishing Awareness Test — V2

Versión visualmente mejorada para una simulación interna autorizada.

## Qué cambió

- Branding ficticio más creíble
- Mejor jerarquía visual
- Responsive móvil
- Favicon
- Estados de carga
- Pantallas de acceso más pulidas
- Botones de proveedores externos simulados
- Página final de aprendizaje

## Límite

La simulación termina inmediatamente después del correo / interacción equivalente.

No existe:
- campo de contraseña
- MFA
- OAuth real
- passkeys
- cookies de sesión
- tokens
- autenticación

## Google Sheets

Pega la URL de tu Web App de Google Apps Script en:

`const ENDPOINT = "";`

dentro de `script.js`.

## GitHub Pages

Sube todos los archivos a la raíz del repositorio y habilita Pages desde la rama `main`.
