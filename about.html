ACERCA

Una mezcla de foro, directorio y memoria de ciudad.

Managua de Noche intenta recuperar la utilidad social de los foros locales: gente preguntando, contradiciéndose, documentando y recomendando desde la experiencia.

Qué queremos evitar

Un directorio donde todo parece perfecto porque solo existen estrellas y fotos bonitas. La ciudad cambia demasiado rápido para eso.

Qué queremos construir

Datos verificables para orientarte, conversación para darte contexto y suficiente estructura para encontrar las cosas otra vez.

V10

Esta versión funciona completamente en GitHub Pages. Los datos de usuario son locales y no hay backend real todavía.
